# Aan Saji — Portfolio Website

This version preserves the original plain HTML/CSS/JavaScript approach and beige/brown visual direction while improving layout, mobile navigation, project presentation, education, and achievements.

## Folder structure
- `index.html` — website content
- `css/style.css` — styles and responsive layout
- `js/script.js` — mobile menu, active navigation, footer year and email CTA
- `images/` — place your own profile/project images here if you want to use them
- `assets/` — place your final resume PDF here when ready

## Before publishing
1. Open `index.html`.
2. Replace `YOUR_EMAIL@example.com` in the email link with the email address you want recruiters to contact.
3. Confirm the FruitScan and DataInsight repository/demo links are still correct.
4. Replace the CSS-made project illustrations with real screenshots when you have them. These illustrations do not depend on local Windows file paths.
5. Add a resume PDF only after you have the final file. The current website intentionally does not link to a missing PDF.

## Test locally
Open `index.html` in a browser. For development, VS Code's Live Server extension is convenient but not required.

## Deploy with GitHub Pages
1. Create or open the GitHub repository you want to use for your portfolio.
2. Upload the contents of this folder (the `index.html` file must be at the repository root).
3. On GitHub, open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish and test the provided live URL on desktop and mobile.

## Accuracy note
Education and project descriptions are based on details previously provided. Keep only the skills and claims you can comfortably discuss in an interview.
